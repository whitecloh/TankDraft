# Инструменты агента
Status: active
Last reviewed: 2026-09-12

Основной агент отвечает за решение и результат. docs-scout читает/ищет и возвращает пути/строки; mech-worker исполняет точный локальный план. Делегировать только независимую ограниченную часть; не делегировать архитектурные решения. При одновременных правках разделять файлы, а при разных задачах — worktree. Для этой задачи главный checkout привязан к открытому Unity.
Контекст читать точечно через rg, не сканировать весь Library/Assets без задачи. Изменённый контракт читать до реализации; отчёт агента — указатель, не замена проверки.
Рабочая ветка codex/*; чужие изменения сохранять; коммит только своей проверенной части, push/merge по поручению.
Editor открыт → MCP; Editor закрыт → допустим batchmode. Проверять путь Editor, не только имя процесса.
После установки MCP отличать живой endpoint от наличия native tools в текущей Codex-сессии. Официальный CLI к тому же endpoint — допустимый MCP-клиент; описать способ проверки.
Регламенты хранятся здесь, проектные имена/модели/endpoint — в .codex и MCP_Setup.md. Глобальные Codex-настройки не менять попутно.
