# TankDraft
Status: approved product direction
Last reviewed: 2026-09-15

Актуальный порядок владельца 15.09.2026: (1) завершить на PC полный клиентский цикл — все окна, механики и функциональные анимации, связь authored configs → data/services → presenters/views, prepared prefabs и LayoutGroups; финальный арт для этого не является блокером. (2) Затем завершить серверную часть PlayFab + Photon Fusion Dedicated с тестовым сервером на ПК: сохранения, экономику, покупки, безопасность и recovery. (3) Затем подключить Unity WebGL + Playgama Bridge к Яндекс Играм как первой внешней тестовой площадке: авторизация, реклама, покупки и браузерная приёмка. Клиент сразу учитывает текущие серверные контракты и ограничения WebGL, но не становится authority. Существующий серверный код сохраняется. VK и Android/iOS не входят в ближайшие этапы; SDK платформ пока не установлены и не проверены. Временные Legacy Catalog/Inventory/Currency, профиль Entity Objects, выключенный Azure и запрет billing/live grants этим порядком не меняются. Единый подробный план: [Functional_Release_Plan.md](../Docs/Features/Functional_Release_Plan.md). Старые приоритеты ниже — исторический контекст.

15.09 приоритет надёжности владельца: простые проверенные решения в разумные сроки; оплаченный товар/прогресс не терять, в исключении допустима контролируемая компенсация в пользу игрока. Исследование, R3.2 operator resolution и границы будущих IAP: [Economy_Reliability.md](../Docs/Features/Economy_Reliability.md). Это не разрешение клиентских grant/retry, реальных платежей или включения billing.

15.09 владелец выбрал временную Legacy Economy для бесплатного QA: Legacy Catalog/Inventory/Currency, профиль Entity Objects, provider адаптер отдельный. V2 не включаем из-за требования payment instrument; billing и Azure не меняем. Это заменяет прежний запрет Legacy в data design. См. [PlayFab_Legacy_QA.md](../Docs/Features/PlayFab_Legacy_QA.md).

Исторический порядок владельца: Android-проверки были отложены, сначала доводился сетевой бой на PC. F4 recovery/ошибки и F5 нагрузка шли без ожидания телефона. Текущие результаты и первичные netcode references: [Fusion_PC_Recovery.md](../Docs/Features/Fusion_PC_Recovery.md). Этот порядок заменён актуальной последовательностью выше.

Актуальное сетевое решение владельца: Photon Fusion 2 Dedicated Server на ПК для тестов, затем перенос server build в облако. Утверждены план, подключение SDK и очистка неиспользуемого стека. См. [Fusion_Dedicated_Migration.md](../Docs/Features/Fusion_Dedicated_Migration.md). Это заменяет прежнюю цель Edgegap и статус PUN как обсуждаемой альтернативы; PlayFab data design сохраняется. Исторические строки ниже описывают предыдущие этапы.

Решение владельца 14.09.2026 о данных: [PlayFab_Player_Data_Design.md](../Docs/Features/PlayFab_Player_Data_Design.md). Профиль хранить в Entity Objects, владение/валюты и магазин — в Economy V2, конфиги — TitleData/Internal TitleData. Azure не возвращаем; старое обязательное размещение custom progression в Azure Tables отменено. Dedicated authority пока сохраняется, вопрос о PUN2 — анализ, не миграция.

Решение владельца 14.09.2026: текущая удалённая QA-приёмка проходит с включённым VPN на клиентах, которым он нужен для доступа. Edgegap остаётся площадкой этапа. Прямой маршрут из России не является критерием этого этапа; это не гарантия доступности релиза. Качество подключения, плавность, server authority и восстановление не ослабляются. План: [VPN_QA_Stabilization.md](../Docs/Features/VPN_QA_Stabilization.md).

Unity 6000.3.10f1, URP 2D; ближайшая целевая площадка — Яндекс Игры через Unity WebGL, PC используется для разработки и приёмки. Android/iOS остаются платформами последующего этапа; исходная композиция portrait сохраняется.
Новый продукт: флоу Draft Showdown с военной техникой от начала XX века до современных средств. World of Tanks — ориентир классов техники, не переход к его управлению/камере.
Полный релиз: live PvP, подходящие по силе боты, коллекция/мастерство/арены/командир/магазин/покупки/реклама/пропуск/рейтинг.
Последнее решение владельца 13.09.2026: временный R1 выполняется без Azure. `TankDraft.RemoteHost` локально готов и проверен: PlayFab identity для account, один bounded authoritative process для queue/matches, server продолжает матч при disconnect, container loss voids незавершённый match без рейтинга/награды. Azure resources и Azure SDK не входят в active deployment graph; прежние adapters изолированы для future durable backend. Partial cloud Windows human acceptance подтверждает same-PC match, offline continuation и rejoin; независимые сети, Android, fault/load и durable acceptance ещё впереди. Edgegap Free Tier и PlayFab cost gates сохраняются. Детали/evidence: [Edgegap_NoAzure_Prototype.md](../Docs/Features/Edgegap_NoAzure_Prototype.md). LocalHost с QA grants не публикуется.
Серверная реализация разрешена владельцем; S1/S2/S3 standalone .NET10/HTTP/security/scheduler/persistence находятся в `Backend`, экспорт и проверки — `Tools/Backend`. Сервер продолжает матч offline; SQLite journal/replay восстанавливает процесс при сохранном диске, durable receipts работают после смены сессии. Outbox проверен с test ledger. Unity loopback WSS transport, очередь и reconnect подтверждены двумя Windows Player и Android USB в LocalOnly QA. Это не public hosting: production identity, distributed storage/lease, radio-network fault matrix и remote PvP ещё впереди; локальная PauseProcessDowntime не утверждает release outage policy. Первые этапы строго без платежей: LocalOnly, cloud launch запрещён до подтверждённого provider-enforced no-charge режима; budgets/alerts его не заменяют. Единый порядок: [Functional_Release_Plan.md](../Docs/Features/Functional_Release_Plan.md); технический план/evidence: [Backend_Implementation_Plan.md](../Docs/Features/Backend_Implementation_Plan.md).
Рабочий процесс и инфраструктурные приёмы берутся из Chibi Arena; его фэнтези-контент, PvE run model, Odin и внешние project IDs не переносятся.
Код нового продукта размещать в Assets/TankDraft; общие UPM-пакеты в Packages. В рабочем дереве есть pre-existing deletions `Assets/ImmortalityLab`; субъект удаления не проверялся, удаления сохраняются и шаблон не восстанавливается без отдельного решения.
