# LeoECS Lite
Status: local fixed-step LeoECS battle implemented; cross-platform/network equality unverified
Last reviewed: 2026-09-12

Подходит для множества однотипных машин/снарядов/эффектов, явного порядка систем и отделения состояния от представления.
Core не зависит от игрового движка; это не Unity DOTS/Burst и не автоматическая многопоточность. EcsLite API не thread-safe. Источник: https://github.com/Leopotam/ecslite .
Использовать существующий com.leopotam.ecslite с закреплением resolved commit; не заменять на другой ECS/fork без причины.
Оригинальный Leopotam/ecslite архивирован владельцем 24.04.2026 (проверено 12.09.2026). Это не мешает использовать небольшой стабильный core, но исправления/поддержка становятся ответственностью проекта; community fork существует, автоматической миграции на него нет.
В ECS: позиции, здоровье, цели, атаки, эффекты, spawn/death. Снаружи: UI/navigation, authoring, аккаунт/покупки/сеть.
Unity-view хранит привязку к стабильному runtime ID и отображает состояние. Не класть Transform/PhotonView/SO в authoritative simulation components.
Порядок систем и fixed-step задаются явно. ECS сам не гарантирует deterministic replay между платформами; это отдельная проверка.
Бой продвигается текущими simulation ticks; на границе тика принимаются разрешённые команды. View читает снимки/события и интерполирует показ, не задавая время попадания, урон или победителя. Предварительный расчёт всей сцены не является условием запуска боя. Ускоренный headless прогон и replay для QA/проверки используют тот же алгоритм и журнал команд; наличие replay не исключает будущие действия игрока в живом бою.
Длительность — критерий балансных прогонов, не игровой таймер исхода. Лимит тестового runner может завершить проверку с диагностикой незавершённого боя, но не объявляет победителя и не меняет правила матча.
Границы сборок описаны в Architecture_Plan.md. Реализованы Target/Movement/Separation/Attack/Projectile/Zone/DamageOutcome в TankDraft.Simulation; текущие ограничения и evidence — в Battle_Prototype.md. Сетевой battle adapter и межплатформенная проверка ещё впереди.
