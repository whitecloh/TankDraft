# Экраны и состояния
Status: layout plan based on video 2; placeholder previz is not approved art
Last reviewed: 2026-09-12

| Экран | Данные/действия | Существенные состояния |
|---|---|---|
| Арена/главная | Текущий уровень, прогресс, армия 4 типов, приказы, в бой | Контент закрыт, слот закрыт, подбор, reconnect |
| Коллекция | Юниты и приказы, фильтры/редкость/роль | Locked, owned, selected, upgrade-ready |
| Карточка техники | Статы, роль/ряд, способности, уровень/мастерство | Недостаток валюты/копий, upgrade-ready, preview |
| Командир | Уровень, прогресс, награды, открытие слотов приказов | Следующий гейт, доступная награда |
| Драфт | Счёт раундов, армии, три оффера, текущий выбор | Камбэк, pending, deadline, waiting |
| Бой | Две армии с отдельными рядами, HP/эффекты, счёт | Начало, flank, spawn/repair, победа/ничья |
| Результат | Победитель, прогресс арены, награды | Pending settlement, retry, reward granted |
| Магазин | Офферы, валюты, платные/rewarded товары | Locked, sold out, pending, restore, failure |
| Пропуск | Уровни и free/premium дорожки | Locked, claimable, claimed |
| Рейтинг | Доступ/лига, место, список | Locked до гейта, loading, empty, error |
| Профиль | Имя, статистика, настройки | Loading, offline/cache, error |

Навигация: главная → коллекция/карточка/командир/магазин/пропуск/рейтинг/профиль; главная → подбор → драфт ↔ бой/итог раунда → результат → главная. Системные загрузка/ошибка/подтверждение покупки не заменяют отдельные фичи.

UI показывает доменное состояние через ViewModel; кнопки посылают команды presenter-у. Pending блокирует повторную отправку, но ошибка даёт корректный retry с тем же operationId. Настоящие цены/баланс/прогресс берутся из сервиса и конфигов, не из текста макета.

Стиль: простые округлённые силуэты, выразительная обводка и крупные цветовые пятна, читаемость на телефоне. Слегка более тёмная палитра без фотореализма. Свои силуэты/иконки/названия техники; ранний canvas-превиз проверяет только композицию. Боевые ряды и счёт различаются без опоры только на цвет.
