## Подтверждённое поведение

1. Обычная подготовка содержит три последовательных выбора, каждый — из трёх карточек. На первом раунде V2 видны 1/3 → 2/3 → 3/3.
2. После проигранного раунда появляется отдельная стадия «Бонус камбэка!» с тремя карточками. Игрок выбирает одну, результат применяется к армии.
3. После бонуса запускается обычная последовательность 1/3 → 2/3 → 3/3. Бонус не заменяет один из трёх обычных выборов. В проверенных переходах проигравший получает суммарно четыре решения перед боем.
4. Бонус получает проигравший последнего раунда. Отставание по счёту матча для его появления не обязательно: в V1 игрок получает бонус, сохраняя преимущество по оставшимся сердцам.
5. В проверенной серии двух поражений подряд в V1 каждый раз выдаётся ровно один бонусный выбор, после него снова три обычных. Увеличения количества бонусных выборов до двух после второго поражения нет.
6. Бонусная тройка может содержать обычное добавление юнитов, UP и ×2. Это не отдельный обязательный тип усиления.
7. Виден тот же номинал конкретных карточек в бонусной и соседней обычной тройке. Поэтому отдельный множитель силы бонусной карточки не установлен. Одинаковые видимые карточки не доказывают равенство скрытых вероятностей генератора.

## Граница точности

Записи не раскрывают:

- веса выпадения обычных и бонусных вариантов;
- правила генерации допустимых UP/×2, их ограничения и численные характеристики;
- полную формулу роста размера пополнения по раундам/состоянию армии;
- все правила энергии, зарядов и доступности магии;
- поведение при исчерпании таймера выбора и строго одновременной гибели армий.

Подтверждён дополнительный выбор. Не подтверждены отдельный численный коэффициент усиления бонусной карточки, повышение вероятности редких вариантов или зависимость весов от серии поражений. Эти неизвестные параметры нельзя выдумать и назвать восстановленной формулой.

## Контракт следующей реализации

Перенос наблюдаемого поведения: `RoundResult → ComebackChoice для проигравшего → NormalChoice 1/3 → 2/3 → 3/3 → Battle`. Перед первым раундом — сразу три обычных выбора. Число вариантов в одной тройке и число последовательных выборов — разные параметры.

Бонусная стадия должна использовать тот же механизм проверки и применения выбранного оффера; отображение отдельного баннера не должно начислять усиление. Бонус выдаётся один раз по результату конкретного roundId; повтор результата/команды не даёт повторного выбора. Применённые изменения относятся к MatchArmy, тогда как HP/позиции/снаряды принадлежат новому RoundState. Постоянный профиль от обычного выбора не изменяется.

Обычный драфт сохраняет точки ожидания соперника между решениями. Нельзя заменить все три выбора единственной карточкой или позволить одной стороне свободно пройти их все, показывая незакоммиченные решения второй стороны. Кнопка магии — альтернативный путь текущего решения; точные затраты требуют отдельного восстановления.

Будущие проверки: первый раунд 3 решения; проигравший 1+3; победитель 3; две потери подряд снова по 1+3; бонус лидирующему игроку после потери раунда; бонус не расходует normalChoiceIndex; применение ровно один раз; четвёртая победа завершает матч без следующего бонуса; ReviewRequired не присуждает сердце и не определяет получателя камбэка.
