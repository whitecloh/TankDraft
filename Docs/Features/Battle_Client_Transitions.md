# Клиентские переходы боя

Дата: 2026-09-15. Статус: локальный клиентский подэтап реализован и проверен в Unity Editor Play Mode на PC. Новые standalone-сборки и live Fusion QA не выполнялись. Общий стиль/3D ждут референсов владельца; текущие примитивы функциональные.

## Контракт

- Авторитетные фаза, ChoiceToken, счёт, состав и SimulationTick берутся из MatchService или server snapshot. Анимация не выбирает карты, не меняет здоровье/урон, не продлевает deadline и не останавливает симуляцию.
- После подтверждённого коммита в Draft показывается выбранная disabled-карта и надпись ожидания. UI помнит только показанный контент и ключ выбора. После reconnect, если выбранная карта неизвестна, остаётся честная надпись ожидания; случайная карточка не подставляется. Во время отправки команды блокируются текущие варианты; авторитетное подтверждение переводит в ожидание.
- Новая подготовка армии сравнивается по стороне/типу/номеру экземпляра. Только прибавившиеся экземпляры получают короткий pop-in. Первая загруженная/восстановленная армия появляется сразу. Перестроенный предпросмотр не должен сохранять чужой prefab при повторном использовании entityId.
- Spawn-анимация меняет только VisualRoot. Серверная позиция, коллайдеры и цель не меняются. Служебные юниты, впервые пришедшие в продолжающемся бою, используют тот же эффект; начальный recovery snapshot подавляет его.
- HUD выводит четыре индикатора жизни на сторону: свои = WinsRequired − победы соперника, соперника = WinsRequired − свои победы. Это отображение опубликованного счёта. Первая загрузка/сброс не изображает только что проигранные раунды; повторный snapshot не повторяет pulse.
- «РАУНД N» и «СРАЖАЙСЯ» — неинтерактивный overlay по возрасту боя. Начальные длительности 1.0/0.8 с, fade 0.12 с, потеря сердца 0.3 с; authored MatchPresentationTimings. UI обновляется каждый frame, между редкими HUD snapshot продолжает только presentation clock. Старый или зависший snapshot не запускает завершившийся баннер заново.
- При переходе фазы, Hide/Disable/смене матча отменяются устаревшие показы. Возврат в уже идущий/завершённый бой не заставляет смотреть пропущенный intro.

## Ограничение относительно референса

В референсе часть надписи «Раунд» показывается до движения, затем «Сражайся» частично перекрывает начало движения. Сейчас authority переходит из Draft непосредственно в Battle. В этом клиентском подэтапе intro накладывается на первые мгновения уже идущего боя; **дополнительная задержка воспроизведения не вводится**. Для точного отдельного предбоевого интервала потребуется согласованный authoritative Prepare/StartAt в следующем сетевом подэтапе. Этот патч не объявляет точную постановку референса полностью воспроизведённой.
