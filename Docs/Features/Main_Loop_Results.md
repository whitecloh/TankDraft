# Возврат из боя и результаты в меню
Status: R3.3a PC PASS; R3.3b progression implementation in Unit_Progression.md, live activation pending
Last reviewed: 2026-09-15

## Объём
Первый подшаг R3.3: меню → серверный бой → результат → меню с актуальным профилем → следующий бой. Прокачка за валюту, магазин и покупки будут отдельным подшагом. R3.3 целиком этим патчем не закрывается.

## Реализация
- `FusionProfileClient` читает ограниченную историю из авторизованного ProfileGet. Проверяет структуру, сторону игрока, победителя, уникальные идентификаторы и состояние награды. История старой версии контента остаётся доступной.
- `ProfileSnapshot` хранит неизменяемую проекцию результата; смена армии её сохраняет. Источники баланса и владения — PlayFab Legacy, источник результата/стадии выдачи — серверный журнал R3.2.
- В authored prefab главного меню добавлена кнопка последнего результата. Она открывает профиль с тремя последними боями: выдано, ожидается, на проверке или пропущено по лимиту QA. Существующие LayoutGroup валют и наград сохранены.
- Клиент никогда не прибавляет показанную награду к балансу. Он перечитывает профиль; сервер сначала фиксирует проекцию истории, затем читает кошелёк, чтобы переход Applied во время запроса не сопровождался более ранним чтением баланса.
- Повтор загрузки и сохранение армии сериализованы. При ошибке остаётся предыдущий валидный профиль. Начальная ошибка входа имеет кнопку «Повторить»; локальный профиль не подставляется.
- Фоновое обновление ограничено authored настройками MetaCatalog: интервал 2000 мс, максимум 3 запроса. Начатый поиск/бой останавливает отложенные попытки. Профиль можно открыть повторно для нового запроса.
- Автоматический QA поиск ждёт готовности профиля и завершения его текущего обновления. Выборы/стоимость/выдача остаются на сервере.

## Границы
Не включались платные сервисы, IAP, Azure или новая экономическая политика. Существующие QA identity и лимиты наград сохраняются. Android и дополнительная оптимизация отложены по решению владельца. Смена армии уже реализована R3.1; платное улучшение требует отдельного серверного контракта стоимости и восстановления неопределённого списания Legacy.
