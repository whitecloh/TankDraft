# Поиск визуального направления TankDraft
Дата: 2026-09-15. Статус: **A1 (светлый) утверждён владельцем; превизы выделены для будущего UI asset pack; сборка ассетов впереди**.

[Утверждённые превизы A1](../../Tools/Previz/Approved/A1-Light/README.md).

Расширенный пакет: [A1/A5 Visual Expansion](A1_A5_Visual_Expansion.md).

## Основание

Владелец предоставил четыре локальных видео и пояснил, что его интересуют два основных направления: цельный авторский минимализм Clusterduck и объёмная техника, эффекты и окружение Tanks A Lot! Tank Sniper задаёт ориентир предельно простой геометрии, Tank Stars — дополнительный пример казуального цвета и эффектов. Задача разрешает новый визуальный поиск после ранее отклонённого концепта; переход рендера и производство игровых моделей пока не утверждены.

Просмотрены 12 распределённых выборок кадров каждого из четырёх видео, всего 48. Это визуальный разбор выборки, не покадровый просмотр полных роликов. Таймкоды и исходные файлы: `Logs/VisualExploration20260915/reference-manifest.json`.

## Набор для согласования

[Галерея: 10 парных листов](../../Tools/Previz/Concepts/2026-09-15-owner-references/README.md). На каждом листе меню слева и активный бой справа. Общая композиция близка к квадрату, каждый экран портретный.

| Код | Художественная гипотеза |
|---|---|
| A1 | Тушь, светлое поле, жёлтые акценты |
| A2 | Пастельная иллюстрация и мягкие формы |
| A3 | Светлые простые 3D-формы с контуром |
| A4 | Картонная диорама с плоскими цветовыми гранями |
| A5 | Светлая техника на тёмном графичном поле |
| B1 | Округлые игрушечные танки и зелёная арена |
| B2 | Гранёная техника и строгий полигон |
| B3 | Рисованный объём и более детальная пустыня |
| B4 | Мягкая арктика и светлый интерфейс |
| B5 | Казуальный 3D с графичным контуром |

Финальные PNG и промпты сохранены рядом с галереей. Встроенный image_gen; отдельные API-ключи и CLI fallback не использовались. Проверка файлов: число, размеры, читаемость PNG и соответствие копий исходникам; визуальный просмотр всех десяти финальных результатов.

## Вывод для обсуждения

A1 наиболее прямо выражает пожелание по минимализму. A3 стоит сравнить с ним как гипотезу объёмного производства. B1 ближе всего к описанию желаемого Tanks A Lot!-направления. B5 связывает объёмную технику с более выраженным графическим контуром. A4 получился объёмной картонной диорамой, а B3 — более детальным; это наблюдения по результатам генерации, не обещание точного соответствия промптам.

## Границы и следующий выбор

Генерированные интерфейсные тексты, числа, стоимость, редкости и иконки — декорация превиза, не новый продуктовый контракт. Количество повторов техники иллюстративно. В некоторых вариантах степень детализации и оформление HUD отклоняются от целевого минимализма; финальная выбранная композиция потребует отдельной выверки. Разные экраны допускается комбинировать только после выбора владельца.

Blender-модели, материалы в Unity, анимации, полнота UI, читаемость массового боя в движении и производительность не проверялись. После согласования художественного направления — уточнение одного комплекта техники/арены и отдельное согласование производственного шага. Текущая подборка не утверждает миграцию 2D→3D.
