## Актуальный порядок

Владелец отложил Android: ближайшая приёмка выполняется на PC. Сохраняем Fusion Dedicated на ПК, .NET/LeoECS authority, PlayFab, закрытый QA без экономики и временно без шифрования. Android не удалён из релиза, но не блокирует F4/F5 на PC. VPN во время сравнений не переключаем.

## Текущий шаг F4

- SDK QuickRejoin настраивается до StartGame. Полный shutdown требует нового runner; его GameObject отделён от постоянного меню/DI scope.
- Сохраняется один FusionQaClient как handle для существующих requests/credentials. Канал конкретного runner заменяется; pending старого канала завершается сетевой ошибкой. Late callback проверяет source runner и instance канала.
- Native inbox инвалидируется при отключении и открывается только после нового Welcome. Старые позы очищаются; новое авторизованное получение Session/SocketOpen восстанавливает текущий серверный снимок. Intent не переотправляется самим bootstrap: это ответственность существующего idempotent transport/journal.
- Полное восстановление ограничено четырьмя попытками, задержки1/2/4/8s, StartGame deadline20s. Отказ авторизации/истёкший Photon ticket прекращает повторы. Автоматическое получение нового PlayFab/Photon ticket после истечения текущего private QA файла ещё отдельно; не скрывать это бесконечным retry.
- Исправлено различение ошибок: IOException от канала/снимков превращается в WebSocketException. Ошибка диска при записи intent остаётся фатальной ошибкой хранения, ошибка сети допускает reconnect.
- В закрытом QA файлы `disconnect` и `reconnect-delay-seconds` внутри приватного runtime directory позволяют автоматизированно остановить реальный SDK runner и отложить повторный вход до90s. Это локальный тестовый сигнал, не внешний игровой API. Он не доказывает восстановление при потере пакетов/VPN timeout.

## Измерения и незавершённые проверки

К существующим cadence/render counters добавлены максимальная длительность private snapshot poll, промежуток публикаций gateway и декодирование native metadata/состояния на клиенте. Эти значения не равны Photon RTT. Времена считаются локальными монотонными часами каждой стороны; межмашинный wall-clock не вычитается. Сравнивать performance без fault injection и screenshot capture.

После этого этапа остаются: управляемая матрица сетевых timeout/QuickRejoin, холодный перезапуск приложения с журналом незавершённого intent, возврат после завершения матча, истечение provider auth, duplicate-account сценарии, потери ACK/атаки, падение server процесса и нагрузка10/20 матчей. Их нельзя считать выполненными по одному успешному reconnect.
