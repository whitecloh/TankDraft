# Сетевое состояние защиты и магазина

Дата: 2026-09-15. Статус: локальная реализация и проверки PASS; отдельная приёмка новых standalone Fusion сборок не выполнена.

## Данные и отображение

`BattleEntityState` содержит `ShieldHp`, `ShieldMaxHp`, `FirstHitBlocks`, `Ammo`, `MagazineSize`, `ReloadRemaining`, `ReloadDuration`. Значения фиксирует общее боевое ядро. Щит исчезает из снимка после истечения даже без нового попадания; перезарядка продолжает отсчёт без подходящей цели в продолжающемся бою. Новый раунд начинает с полным магазином и готовым личным блоком. Неиспользуемые поля и состояния снарядов/зон равны нулю.

Путь данных: симуляция → detached server snapshot → JSON / binary codec / native Fusion replica → обе клиентские проекции положения → `BattleEntityView` → `BattleDefenseIndicators`. Дискретные состояния не интерполируются между разными снимками. UI не расходует заряды, не продвигает серверный reload и не принимает боевых решений.

Все 22 unit-prefab содержат подготовленные дочерние элементы:

- голубая полоса — оставшийся щит относительно запаса текущей выдачи;
- светлый ромб справа от HP — готовый блок первого попадания;
- жёлтая полоса — доля оставшихся выстрелов;
- сине-фиолетовое заполнение — прогресс перезарядки по последнему снимку.

Неактуальные индикаторы скрываются. `Bind/Clear` сбрасывают видимость, цвет и масштаб для повторного использования пула. Это простые функциональные индикаторы в существующем sprite-HUD, не новое художественное направление. Авторинг через `TankDraft/Battle/Author Defense Indicators` и `PrefabUtility`, без создания элементов HUD во время боя. Базовый BattlePrototype authoring также создаёт необходимые ссылки.

## Совместимость и границы

Версия состояния `BattleEntityState.WireVersion = 2`: server snapshot публикует `BattleStateVersion`, клиент требует точное совпадение даже для пустого списка сущностей. Новые JSON-поля обязательны и проверяются по типам/диапазонам. Бинарный frame получает префикс версии, все новые поля участвуют в shared hash. Команды/ACK и отдельный WebSocket handshake `tankdraft-server-v2` не менялись — это разные контракты.

Fusion entity/header расширены, несоответствие версии проверяется до чтения entity array. 7 дополнительных полей × 4 bytes × 256 slots = 7168 bytes дополнительного фиксированного состояния. Фактический размер сгенерированной реплики — **37428 bytes**. Локальный `Heap.PageShift=16` задаёт страницу65536 bytes, прежняя32768 недостаточна. Частота snapshot и лимиты entities/events не увеличивались. Фактический сетевой трафик не измерен в этом патче.

Нужно совместно пересобрать authority/server, Unity Fusion gateway и игровые клиенты. Смешивание старых и новых сборок не поддерживается; старые battle snapshots не следует трактовать как отсутствие щита/магазина. Существующие журналы/сохранения не мигрировались и не удалялись; сохранённый матч уже защищён проверкой BuildVersion в MatchRecipe. Live PlayFab/экономика/аккаунты и опубликованные серверы не менялись. ContentVersion остаётся хэшем контента; баланс в этом патче не изменён.
