TankDraft — закрытый тест на Windows

Этот пакет предназначен для ОДНОГО тестера. В нём уже настроен отдельный
тестовый аккаунт. Не публикуй архив и не запускай его одновременно
на нескольких компьютерах: они будут входить под одним аккаунтом.

Как запустить
1. Полностью распакуй ZIP в отдельную папку. Из архива игру не запускай.
2. Уточни у организатора, что сервер включён, и получи текущий код сервера.
3. Открой StartGame.cmd. Вставь код и нажми Enter.
   Если организатор подтвердил, что код из пакета ещё актуален,
   можно просто нажать Enter, оставив предложенный код.
4. Дождись открытия меню, затем нажми «В БОЙ».

Unity, Unity Hub и .NET SDK устанавливать не нужно.
Нужны Windows 10/11 x64, интернет и штатный Windows PowerShell.
В текущих тестах из России требуется включённый VPN; оставь его включённым
на протяжении игры. Первый вход может занять около минуты.

Что важно в этой тестовой версии
- Сервер работает на компьютере организатора. Если он выключен, игра
  не подключится. Это не автономная версия с локальным боем.
- После каждого перезапуска сервера код меняется. Сам ZIP менять не нужно:
  при следующем запуске введи новый код, полученный от организатора.
- Один серверный сеанс ограничен 30 минутами; в последние 5 минут новые
  поиски недоступны. Для следующего сеанса организатор перезапускает сервер.
- Поиск противника длится 10 секунд; затем сервер может назначить бота.
- Пока поддерживается один приказ усиления брони или пустые слоты приказов.
  При сообщении «Отряд пока не поддерживается» закрой его и измени отряд.
- Прогресс относится к тестовому аккаунту; реальные покупки не тестируем.

Если не запускается
- Если ошибка содержит private runtime setup, запусти CheckRuntime.cmd.
  Он проверяет папки и права Windows без входа в аккаунт и запуска игры.
  При ошибке передай строку Runtime diagnostic (step/type/hresult).
- Запускай StartGame.cmd, а не файл игры в папке Game.
- Закрой прежнее окно игры перед повторным запуском.
- Проверь код сервера, его готовность у организатора и VPN.
- Окно запуска сообщит этап ошибки и путь к журналу. Передай организатору
  описание проблемы и файл player.log из указанной папки Logs.
- Не присылай файлы TesterAccess.json, auth.json и gateway.json:
  они содержат данные входа. Не отключай защиту Windows ради запуска;
  если файл заблокирован, сообщи организатору точный текст предупреждения.

Игра и окно запуска не требуют прав администратора.
