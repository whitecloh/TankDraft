# TankDraft Previz

Локальный инструмент для схем экранов TankDraft. Откройте `index.html` двойным кликом в современном браузере: сервер, SDK, CDN и внешние шрифты не нужны.

Canvas рисует portrait-layout в выбранном viewport, включая safe area. Масштаб `Авто` подгоняет полный телефонный превиз по высоте окна; `100%` оставляет исходный масштаб для детального просмотра. Выберите экран, состояние и язык, затем кликните элемент схемы и измените его label и координаты в правой панели. Экран боя использует четыре ряда: преграды, танки, ПТ и САУ; обозначения военные и схематичные.

`Layout JSON` экспортирует версионированную schema v1 либо v2. v1 сохранён для совместимости; v2 добавляет корневые `groups` и element `parentId`. Полный контракт с примером приведён в `SCHEMA.md`. Импорт проверяет версию, типы, координаты, уникальность ID, лимиты и разрешённые kinds до отображения. PNG экспортируется непосредственно из того же canvas без рамки выбранного элемента, а Markdown содержит спецификацию текущего экрана. После каждого экспорта под кнопками остаётся явная ссылка `Скачать <имя>` для браузеров, где автоматическое скачивание блокируется; предыдущий object URL при следующем экспорте отзывается. Выбранная локальная reference image отображается рядом с canvas, хранится только через browser object URL и ни в один экспорт не попадает.

Главная содержит authored `group.wallet` (ячейки 120 × 48, spacing 10) и `group.rewards` (81 × 87, spacing 10, `MiddleCenter`). Группы доступны для выбора в списке; можно менять geometry, alignment и type. Перетаскивание группы передвигает всех членов, а geometry её членов блокируется. Дублирование и удаление группы, а также membership происходят через authored source; неподдержанные UI-операции отклоняются. Остальные 23 окна пока плоские.

Повторяемая проверка: `node verify.cjs` подтверждает 24 кадра, 72 layout и 27 случаев matrix групп. Отдельная legacy schematic suite сохраняет 1056 сочетаний и негативные проверки. Опция `node verify.cjs --export-dir <папка>` сохраняет экспортные JSON для внешнего smoke-потребителя; по умолчанию файлов не создаёт.

Переключение экрана, состояния, языка, viewport или полей может перестроить пресет; при несохранённых изменениях инструмент предлагает сначала экспортировать JSON. Цвета темы меняют текущий layout без его сброса. Это превиз интерфейса, не финальный арт и не реализация Unity/C#.
